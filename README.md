# CheckJump (anonymous code and results for review)

`b25` in file names means CheckJump. Optimizer: `jumping_adam_simpson_b25.py` (sha256 prefix 0b63021273376f1e). Search space: `official_fields.py` (07d3598d8c8b9eaa; the wide-box runs use 4259c902e9f36a9e). One folder per experiment; `_checks/` holds the ablations (M), batch controls (R) and diagnostics (D). `best_hparams.csv` lists the selected hyperparameters for all seven arms.
